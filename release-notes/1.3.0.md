## What's new

- **Windows app** – the full player on the desktop, with a sidebar, queue/lyrics panel, keyboard shortcuts, right-click menus and media keys.
- **Sleep timer**, playback speed, crossfade between songs and an equalizer (Android).
- **Synced lyrics** from `.lrc` files next to your songs.
- More sort options (duration, most played) and a "Liked only" filter.
- **Automatic updates** – the app checks GitHub for new versions and installs them for you.
- **Discord Rich Presence** on Windows – show what you're listening to.
- Smoother swipe-to-dismiss and track-swipe gestures.
- New app icon.
