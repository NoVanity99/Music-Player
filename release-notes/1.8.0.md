## What's new

- **Artist pages**: each row now starts with the newest release on the left. A new **Unreleased songs** row sits under Custom albums, and the long Songs list at the bottom is gone.
- **Themes**: pick an accent colour (rose, orange, green, teal, blue or purple) and turn on **Pure black** in Settings.
- **One-click installers**: `VanityPlayer-Installer.exe` and `VanityPlayer-Installer.apk` always download and install the newest version, so they're the only files you need to share.
